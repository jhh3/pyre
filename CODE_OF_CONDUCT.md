# Code of conduct

Pyre follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the work. Harassment, personal attacks, and publishing other people's private information are not acceptable in any project space: issues, pull requests, discussions, or anywhere you represent the project.

## Reporting

Report unacceptable behavior to the maintainers privately. Use a private security advisory (the repository's **Security** tab → **Report a vulnerability**) and start the title with "Conduct:". Reports are kept confidential. Maintainers will review each report and respond in proportion to it, as described in the Covenant's enforcement guidelines.
